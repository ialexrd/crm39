# ЧИСТКА39 CRM

Новая версия CRM для выездной химчистки мягкой мебели.

План: скопировать интерфейс из `ialexrd/crm`, заменить логотип на «ЧИСТКА39» и цветовые акценты на `#2563EB`. Исходный репозиторий не изменяется.

**Безопасность:** перед запуском требуется отдельный тестовый проект Firebase; подключения действующей базы и Google Таблиц сюда не копируются.
